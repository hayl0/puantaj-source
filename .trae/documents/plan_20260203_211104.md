# API Yönlendirme ve Giriş Sorunu Çözüm Planı

API isteklerinin (`/api/auth/csrf`) HTML sayfası döndürmesi sorununu çözmek için aşağıdaki adımları izleyeceğim:

1.  **Dosya Adını Geri Döndür (`middleware.ts`):**
    *   `proxy.ts` dosyasını tekrar `middleware.ts` olarak değiştireceğim.
    *   **Neden?** Next.js 16 "deprecated" uyarısı verse de, kullandığımız `next-intl` ve `next-auth` kütüphaneleri henüz `proxy.ts` yapısıyla tam uyumlu çalışmıyor olabilir. Bu uyumsuzluk, API isteklerinin yanlış yönlendirilmesine sebep oluyor. "Uyarı almak", "sitenin çalışmamasından" daha iyidir.

2.  **Matcher Ayarını Güçlendir:**
    *   `middleware.ts` içindeki `config.matcher` ayarını güncelleyerek `/api` ile başlayan tüm isteklerin middleware tarafından **kesinlikle** yok sayılmasını sağlayacağım.
    *   Mevcut Regex yapısını daha basit ve güvenilir bir hale getireceğim.

3.  **Dağıtım ve Test:**
    *   Değişiklikleri GitHub'a göndereceğim (Vercel otomatik dağıtacak).
    *   Dağıtım sonrası `test-login.mjs` aracımla giriş işleminin JSON döndürüp döndürmediğini tekrar kontrol edeceğim.
